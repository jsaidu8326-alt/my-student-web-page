
# Student Portfolio and Academic Management Website

## Project Overview

This project is a responsive multi-page website developed using
HTML, CSS, and JavaScript as part of a practical term project.

It combines a personal academic portfolio with an interactive
academic task management system.

## Features

- Homepage with student profile and biography
- About Me page with education, skills, and career goals
- Projects page featuring three sample projects
- Academic planner with add, complete, and delete functionality
- Browser local storage for academic tasks
- Contact form with JavaScript validation
- Responsive design for desktop and mobile devices
- Multimedia video demonstration

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- Git and GitHub

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html in a browser.
4. Navigate between the pages using the navigation menu.

You can also use the Live Server extension in Visual Studio Code.

## Project Structure

- index.html: Homepage
- about.html: About Me
- projects.html: Projects
- planner.html: Academic Planner
- contact.html: Contact Form
- style.css: Website styling
- script.js: Interactive functionality
- images/: Student photograph and project images
